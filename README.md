# StudyTree (스터디트리) 🌳

> **계층형 학습 아웃라이너 & 지식 트리 웹 애플리케이션**  
> 고교 한국사·사회 탐구부터 의약학 메디컬 스터디(작용기전 MOA, 상호작용 DDI, 복약지도)까지 무한 계층으로 정리하고 암기 상태를 트래킹할 수 있는 워크스페이스입니다.

---

## ✨ 핵심 기능

1. **2단 분할 워크스페이스 & 인디고-슬레이트 감성 디자인**
   - 좌측 계층형 트리 탐색기(무한 Depth, 들여쓰기 가이드 라인, `+`/`-` 폴딩 배지)
   - 우측 실시간 학습 상세 에디터(제목, 1줄 핵심 요약, 상세 학습 노트 & 마크다운 미리보기)
   - 눈이 편안한 인디고-슬레이트 톤, 원클릭 다크/라이트 모드 지원

2. **암기 달성도 및 상태 트래킹 시스템**
   - `미학습(회색)` / `학습중(주황)` / `암기완료(초록)` 3단계 상태 및 `중요(★)` 마킹
   - 암기완료 시 축하 컨페티(Confetti) 효과
   - 하단 상태 바에서 실시간 암기 달성률(%) 및 프로그레스 바 제공

3. **스마트 트리 조작 & 키보드 단축키**
   - 제목 입력창에서 `Enter`: 같은 레벨의 새 형제 항목 생성
   - `Tab`: 들여쓰기 (앞선 항목의 하위 자식으로 이동)
   - `Shift + Tab`: 내어쓰기 (상위 레벨로 승격)
   - 호버 액션: `+하위`, `+형제`, `↑`/`↓` 순서 이동, `삭제`

4. **멀티 노트북 & 실시간 검색 & 백업**
   - 다중 노트북 생성, 이름 변경, 삭제 지원
   - 제목/한줄요약/노트 실시간 통합 검색 (일치 항목의 모든 상위 조상 자동 펼침 & 하이라이트)
   - JSON 파일 백업 내보내기 & 불러오기, 원클릭 샘플 데이터 초기화
   - 모든 데이터는 `localStorage`에 자동 영구 보존

5. **전문 샘플 데이터 기본 탑재**
   - **`[샘플] 고교 한국사 - 근현대사 핵심 정리`** (흥선대원군 개혁부터 6월 민주항쟁까지)
   - **`[샘플] 약학 스터디 - 심혈관계 약물 정리`** (RAAS 억제제, CCB, 베타차단제, 이뇨제 기전·DDI·복약지도)

## 🚀 실행 방법

### 개발 모드 실행
```bash
npm run dev
```
브라우저에서 `http://localhost:5173` 접속

### 프로덕션 빌드
```bash
npm run build
npm run preview
```
또는 빌드된 `dist/index.html`을 정적 호스팅(Vercel, GitHub Pages, Firebase Hosting 등)에 즉시 배포할 수 있습니다.
